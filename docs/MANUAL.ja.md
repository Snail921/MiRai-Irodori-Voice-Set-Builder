# MiRai Irodori Voice Set Builder 操作マニュアル

[English](MANUAL.en.md) | 日本語 | [READMEへ戻る](../README.md)

## 1. 概要

このBuilderは、起動済みのMiRai Server for Irodori-TTS V4へHTTPリクエストを送り、用途・状態別のWAVボイスセットを作成するツールです。

生成対象のタイプは次の9種類です。

1. `Default`
2. `LowArousal`
3. `MediumArousal`
4. `HighArousal`
5. `NearOrgasm`
6. `Orgasm`
7. `Hypersensitive`
8. `Overdrive`
9. `DeepOrgasm`

## 2. 事前準備

### 2.1 uvをインストールする

[uv公式ドキュメント](https://docs.astral.sh/uv/getting-started/installation/)に従ってインストールし、新しいコマンドプロンプトで次を確認します。

```bat
uv --version
```

### 2.2 Irodori-TTSサーバーを準備する

[MiRai Server for Irodori-TTS V4](https://github.com/Snail921/MiRai-Server-for-Irodori-TTS-V4) のREADMEに従ってセットアップし、`start_mirai_server.bat` を起動します。

既定の接続先は次のとおりです。

```text
http://127.0.0.1:5000
```

ブラウザーで `http://127.0.0.1:5000/health` を開き、応答が返ることを確認してください。参照voiceはTTSサーバー側の `voices` フォルダーに配置します。

## 3. Builderを起動・終了する

1. `Start_IrodoriVoiceSetBuilder.bat` をダブルクリックします。
2. 初回のみ、依存パッケージの準備が完了するまで待ちます。
3. ブラウザーで `http://127.0.0.1:7860` が自動的に開きます。
4. 終了するときは、Builderのコマンド画面で `Ctrl+C` を押します。

ブラウザーが自動的に開かない場合は、表示されたURLを手動で開いてください。Builderのコマンド画面を閉じるとGUIも停止します。

## 4. Generationタブ

![Generationタブ](images/generation.png)

### 4.1 サーバーへ接続する

「TTSサーバーURL」に接続先を入力し、「接続確認」を押します。成功時にはvoice数とランタイムの読み込み状態が表示されます。

### 4.2 共通項目

- **参照voice**: TTSサーバーの `voices` に登録されているIDを入力します。大文字・小文字は区別せず照合されます。
- **ステップ数**: `1`～`120` の整数です。既定値は `40` です。

存在しない参照voiceは生成前に検出されます。TTSサーバーがno-reference推論へフォールバックした場合も、Builderは生成を停止します。

### 4.3 タイプごとの項目

- **有効**: 画面下部の一括Generateに含めるかを指定します。
- **テキスト**: TTSへ送る文章です。複数候補は `/` で区切ります。句読点、カンマ、改行は区切りとして扱われません。
- **Caption（任意）**: 声質、感情、話し方などの説明です。空欄ならcaptionを送信しません。
- **各テキストの出力数**: `/` で分割した各文章を何回ずつ生成するかを指定します。
- **Sample**: 候補を1件だけ一時生成し、Sample Previewで再生します。押すたびに `/` 区切りの次の候補へ進みます。
- **Generate**: そのタイプだけを即時生成します。「有効」のチェック状態には影響されません。

例えばテキストが `おはよう/こんにちは`、出力数が `3` の場合、そのタイプに合計6クリップを生成します。

### 4.4 一括生成する

画面下部のオレンジ色の **Generate** を押し、確認ダイアログで実行を承認します。有効なタイプだけが上から順に処理されます。生成中はウィンドウやサーバーを閉じないでください。

正常終了すると、生成ログとファイル一覧が表示され、画面下部の「Arrangeタブへ」と画面右端の縦長の「Arrange画面へ」が緑色になって有効になります。生成中または生成失敗時は無効です。どちらのボタンからでもArrangeタブへ移動でき、生成したボイスセットが自動的に選択されます。画面幅が狭い場合は、操作欄との重なりを避けるため右端ボタンが非表示になり、下部ボタンだけが表示されます。

### 4.5 出力先とファイル名

```text
output/<参照voice>/<タイプ>/[Common]<テキスト>_000.wav
```

同名ファイルがある場合は `_001`、`_002` のように空いている番号を使用し、上書きしません。Windowsで使えないファイル名文字は `_` に置換されます。TTSへ送る文章は変更されません。

## 5. Arrangeタブ

![Arrangeタブ](images/arrange.png)

### 5.1 ボイスセットを表示する

「ボイスセット名」で対象を選択します。外部でファイルを追加した場合は「一覧を更新」を押してください。全タイプのクリップがカード形式で表示され、カード内のプレイヤーから再生できます。

### 5.2 分類プレフィックス

各クリップには `Common / Continue / EaseUp / Change / Stop / Fawn` の分類を指定できます。分類はファイル名先頭の `[Common]` のようなプレフィックスとして保存され、カード上では色付きマークで確認できます。

### 5.3 追加タグ

クローン直後は次のタグが「利用可能な追加タグ」に設定されています。

```text
vm/Nod/LeanBack/Shudder/Convulse/HeadShake/LookDown/TurnAway/HeadTilt/HeadBack/ChinTuck/tear
```

選択肢を変更する場合も `/` 区切りで入力します。カードの「追加タグ」、または編集画面から複数のタグを付けられます。追加タグは `[HeadShake]` のようにファイル名へ保存されます。

### 5.4 クリップを編集する

カードの「編集」を押すとトリミング画面が開きます。表示ファイル名、分類プレフィックス、追加タグ、開始・終了位置、フェードイン・フェードアウト秒数を変更でき、選択範囲を試聴できます。

拡張子を省略した場合は `.wav` が補われます。同名ファイルがある場合は、空いている連番が提案されます。編集前の音声はボイスセット内の `.trash/edits/<タイプ>/` にバックアップされます。

### 5.5 複製・移動・削除

- **複製**: 同じタイプ内にコピーし、空いている連番を割り当てます。
- **移動**: カード左側のドラッグハンドルを別タイプの列へドロップします。移動先に同名ファイルがあれば自動改名されます。
- **削除**: 確認後、ファイルを `.trash/<元タイプ>/` へ移動します。完全削除ではありません。
- **全削除**: そのタイプの全クリップを `.trash` へ移動します。
- **全タイプを一括削除**: 選択中ボイスセットの全クリップを `.trash` へ移動します。

「確認をスキップ」は個別カード削除の確認だけを省略します。全削除の確認は省略されません。

### 5.6 連番を振り直す

「連番を振り直す」は、全タイプを対象に、分類・追加タグを除いたテキストごとの番号を `_000` から整理します。番号の欠落や重複末尾も正規化し、分類のないファイルには `[Common]` を追加します。

## 6. 自動保存される設定

TTSサーバーURL、参照voice、ステップ数、各タイプの入力、追加タグ候補、削除確認設定はルートの `settings.json` に保存され、次回起動時に復元されます。

`settings.json` と `output/` はGit管理対象外です。初期状態へ戻す場合は、Builderを終了してから `settings.json` を削除してください。

## 7. トラブルシューティング

### `uv was not found in PATH`

uvをインストールし、新しいエクスプローラーまたはコマンドプロンプトから再実行してください。`uv --version` で確認できます。

### TTSサーバーに接続できない

- TTSサーバーの起動完了ログを確認します。
- `http://127.0.0.1:5000/health` をブラウザーで開きます。
- サーバーのポートを変更した場合はGUIのURLも変更します。
- 別PCのサーバーへ接続する場合は、そのPCのLAN IPとファイアウォール設定を確認します。

### 参照voiceが見つからない

TTSサーバーの `http://127.0.0.1:5000/voices` を開き、表示された `id` をそのまま入力してください。

### Builderのポート7860が使用中

```powershell
$env:IRODORI_BUILDER_PORT = "7861"
uv run --locked python app.py
```

### 生成が途中で失敗する

生成済みファイルはそのまま残ります。エラー表示とTTSサーバー側のログを確認し、問題を解消してから再実行してください。既存ファイルは上書きされません。
